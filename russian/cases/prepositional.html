Prepositional Case

Usage

The prepositional case is used after, well, prepositions. Not all of them, but it gets its name from the fact that it always requires a preposition to use it. The prepositions that take this case are:

о (about)

при (under (ruler))

в (in(side)) (also used with accusative for motion: into)

на (on) (also used with accusative for motion: onto)

Important Aspects of Prepositional Case

  1. when о transforms

    2. when before two consonants (мне/всех/что-либо), it is written as обо

    when before vowel it is written as об

  2. Every inanimate noun either takes в or на

    3. в is used for almost everything

    на is only used for:

    activities (e.g., урок, занятие, лекция, работа, концерт)

    things you are on the surface of (e.g., улица, площадь)

    things that were historically roofless (e.g., стадион, станция, вокзал)

    other things (e.g., кафедра, дача, завод, на севере, islands, peninsulas)

  3. When something is "in" a language (use на + adjective of the language in the masculine singular prepositional form)

    4. я читаю на русском (I read in Russian)

    книга на английском (a book in English)

  4. There are many irregular masculine singular words that have a -у ending, often mono-syllable words. Here are the most common ones:

    5. аэропорт → аэропорту

    берег → берегу

    лёд → лду

    год → году

    пол → полу

    сад → саду

    снег → снегу

    угол → углу

    шкаф → шкафу
